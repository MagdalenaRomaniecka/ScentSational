## 🧠 The Dual-Engine Architecture

To optimize performance and user experience, the ecosystem is divided into two specialized units:

| **⚜️ THE ATELIER (This Repo)** | **🧪 THE AI CORE (Neural Engine)** |
| :--- | :--- |
| **Role:** Visual Intelligence & Market Analytics | **Role:** Deep Learning & Recommendation System |
| **Tech:** Streamlit, Plotly, Pandas, Regex | **Tech:** SBERT, PyTorch, Vector Embeddings |
| **Focus:** Exploring metadata, analyzing volume trends, and filtering the catalog by brands/notes. | **Focus:** Analyzing the **chemical description** to find perfumes that *smell* similar, ignoring brand marketing. |
| 📍 **[You are here]** | 🔗 **[Go to AI Core](https://github.com/MagdalenaRomaniecka/ScentSational-Fragrantica-LFS)** |

## 🛠️ Installation & Local Usage

To run the Atelier locally on your machine:

```bash
# 1. Clone the repository
git clone [https://github.com/MagdalenaRomaniecka/ScentSational.git](https://github.com/MagdalenaRomaniecka/ScentSational.git)

# 2. Navigate to the directory
cd ScentSational

# 3. Install requirements
pip install -r requirements.txt

# 4. Launch the Atelier
streamlit run app.py
